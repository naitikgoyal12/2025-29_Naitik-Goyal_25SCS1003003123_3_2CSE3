## 🚀 Projects

### 1. 🌾 Agriculture Crop Production Prediction

This project focuses on predicting agricultural crop production using historical agricultural data.

#### Key Activities
- Data preprocessing
- Data cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Machine Learning model development
- Model evaluation
- Actual vs Predicted analysis
- Feature importance analysis

#### Evaluation Metrics
- MAE (Mean Absolute Error)
- RMSE (Root Mean Square Error)
- R² Score

---

### 2. 🚦 Smart City Traffic Forecasting

This project focuses on forecasting traffic volume and identifying peak traffic periods in a smart-city environment.

#### Key Activities
- Traffic data preprocessing
- Date-time analysis
- Exploratory Data Analysis
- Hourly traffic analysis
- Daily traffic analysis
- Weekday vs Weekend comparison
- Weather vs Traffic analysis
- Feature engineering
- Traffic forecasting
- Peak traffic prediction

#### Time-Based Features
- Hour
- Day
- Weekday/Weekend
- Month
- Peak-hour indicator
